# Security Policy

## Supported Versions

Currently, only the latest version of Rabbit Base is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly. 
Instead, please email the project maintainers directly or use the GitHub Security Advisories "Report a Vulnerability" feature if enabled.

Please include the following information in your report:
- Type of vulnerability (e.g. XSS, SQLi, etc.)
- Step-by-step instructions to reproduce the vulnerability
- Any proof of concept (PoC) code or screenshots

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. If the vulnerability is accepted, we will create a patch and release a new version.
